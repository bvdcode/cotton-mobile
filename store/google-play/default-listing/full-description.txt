Cotton Cloud for Android is a focused folder-sync client for your Cotton Cloud instance.

Current features:

- Connect to a Cotton Cloud instance by entering its URL.
- Approve access in the browser through the Cotton app-code authorization flow.
- Restore your secure session when the app starts again.
- Choose a cloud folder and a folder on your Android device.
- Upload new and changed files from the selected device folder.
- Keep local originals or delete them only after a confirmed upload.
- Synchronize changes in both directions with an explicit review before destructive actions.
- Run, pause, resume, refresh, and stop each configured sync root.
- Sign out and clear local session data when needed.

Cotton Cloud mobile is currently distributed through testing tracks while the sync experience is refined.
